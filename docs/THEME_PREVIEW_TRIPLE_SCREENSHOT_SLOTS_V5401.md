# v5.401 ThemePreviewAndTripleScreenshotSlots

## Theme Preview
- Theme select 변경 즉시 선택 Layout과 Theme을 결합한 미니 미리보기를 표시한다.
- 전체 미리보기는 Desktop/Tablet/Mobile viewport를 지원한다.
- 메뉴 Normal/Hover/Active, Header, Sidebar, Button, Input, Card를 Design Token 및 component_rules로 렌더링한다.

## Screenshot Slots
- Theme Import에는 화면 캡처 1, 2, 3의 독립적인 파일 첨부 슬롯을 제공한다.
- 각 슬롯은 최대 25MB 이미지 1개를 선택하며 개별 교체/삭제한다.
- 선택된 최대 3개 이미지를 통합 분석하여 Theme Token과 메뉴 상태 규칙을 만든다.
