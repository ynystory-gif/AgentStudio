# v5.337 Manual Requirement Draft Restore & Legacy Draft Sanitizer Fix

## 문제

신규 Agent에서 기존에 사용한 프로젝트 경로를 다시 선택하면 해당 경로에 저장된 요구사항 Draft가 자동 복원되었다. v5.334~v5.336 시기에 저장된 Draft에 첨부 파일 원문/긴 코드 출력이 포함되어 있으면 새 인터뷰 화면에 깨진 과거 내용이 다시 나타날 수 있었다.

## 수정

- 프로젝트 경로 선택과 이전 요구사항 Draft 복원을 분리했다.
- 같은 경로의 Draft가 있어도 자동 복원하지 않는다.
- 우측 패널에 `이전 요구사항 이어서 불러오기` / `현재 인터뷰 유지` 선택을 표시한다.
- 사용자가 선택하기 전에는 현재 인터뷰 autosave가 기존 Draft를 덮어쓰지 않는다.
- 이전 Draft 복원을 선택하면 오래된 assistant 코드 덤프/첨부 원문 출력 패턴을 자동 차단한다.
- 신규 Agent 시작 시 Draft 후보/복원 상태를 초기화한다.

## 기대 동작

프로젝트 경로를 지정해도 현재 새 인터뷰는 그대로 유지된다. 과거 요구사항은 사용자가 명시적으로 선택한 경우에만 복원된다.
