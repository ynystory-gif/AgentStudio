# THEANOVA AgentStudio v5.493 - RuntimePathPolicy

- Temp 기본 경로를 Python/pip/npm/Browser Runtime의 실제 임시 경로로 적용
- Cache 기본 경로를 pip/npm/Hugging Face/Torch/EasyOCR/Browser Profile의 실제 캐시 위치로 적용
- Output 기본 경로를 PPT/ERD PNG/SQL/녹음/Transcript/요약/브라우저 다운로드 저장 위치로 적용
- 저장된 결과의 실제 절대 경로를 UI에 표시
- Temp와 Output이 다른 드라이브여도 저장 지원
