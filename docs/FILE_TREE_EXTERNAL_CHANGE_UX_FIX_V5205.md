# v5.205 File Tree + External Change UX Fix

- 프로젝트 파일을 클릭해 열 때 Monaco Editor로 포커스를 강제로 이동하지 않습니다. 사용자가 실제 코드 영역을 클릭했을 때만 Editor focus가 활성화됩니다.
- 프로젝트 파일 트리에서 Ctrl/Cmd 클릭 및 Shift 클릭으로 파일 멀티 선택을 지원합니다.
- 선택한 파일은 DEL 키 또는 우클릭 `파일 삭제` 메뉴로 삭제할 수 있으며, 실제 디스크 삭제 전에 `정말 삭제하시겠습니까?` 확인 Dialog를 표시합니다.
- Backend `/files/delete`는 프로젝트 root 경계 안의 파일만 삭제하며 폴더는 파일 삭제 API로 제거하지 않습니다.
- AgentStudio에 미저장 변경이 있는 열린 파일이 외부에서 수정되면 `외부에서 수정이 되었습니다. 수정된 외부 파일 로드하시겠습니까?` Dialog를 표시합니다. OK를 선택하면 외부 디스크 내용을 다시 읽고 로컬 미저장 내용을 교체합니다.
- 현재 보고 있지 않은 열린 파일의 외부 수정/삭제는 상단 알림 아이콘에 모아 표시하고, 알림 메뉴에서 변경 파일과 상태를 확인할 수 있습니다.
