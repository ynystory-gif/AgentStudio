# v5.400 CodeToolbarRightPanelFit

- 코드 편집기 상단 도구가 우측 `프로젝트 파일 / AI 변경 제안 / DB 연결 / Codex` 패널 아래로 들어가거나 잘리는 문제를 수정했습니다.
- `전체 실행 / 선택 실행 / 실행 정지` 같은 실행 계열 버튼을 최우선 순서로 배치해 항상 먼저 보이도록 했습니다.
- 찾기, 디버그, 북마크 같은 보조 도구는 같은 한 줄 안에서 유지하되 공간이 부족하면 도구 영역 내부에서만 가로 스크롤할 수 있습니다.
- 도구 영역에 우측 여백을 추가해 `전체 실행 F5` 버튼 테두리/단축키가 우측 패널 경계에 붙거나 가려지지 않습니다.
- Code workspace의 폭은 우측 패널을 침범하지 않도록 계속 `min-width:0`/`overflow-x:hidden` 계약을 유지합니다.
