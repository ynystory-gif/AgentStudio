# v5.177 Editor Unsaved Close Dialog

## 목적
코드 편집기에서 저장되지 않은 파일을 닫을 때 데이터 손실을 방지하면서 사용자가 닫기 방식을 명확히 선택할 수 있도록 합니다.

## 적용 대상
- 개별 파일 닫기
- 열린 파일 모두 닫기
- 핀 고정되지 않은 파일 모두 닫기

## 동작
닫기 대상에 dirty 파일이 하나라도 있으면 다음 메시지를 표시합니다.

`저장되지 않은 파일이 있습니다. 정말 닫겠습니까?`

버튼:
1. `저장하고 닫기`: 닫기 대상의 dirty 파일을 모두 저장한 뒤 저장이 전부 성공한 경우에만 닫습니다. 저장 실패 파일이 있으면 닫지 않고 오류를 표시합니다.
2. `저장 안하고 닫기`: 저장하지 않고 요청된 대상 파일을 닫습니다.
3. `취소`: 아무 파일도 저장하거나 닫지 않습니다.

핀 고정되지 않은 파일 모두 닫기에서는 핀 고정된 파일은 대상에서 제외됩니다.
