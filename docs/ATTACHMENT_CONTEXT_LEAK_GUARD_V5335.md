# v5.335 Attachment Context Leak Guard

Agent 설계 인터뷰에서 대용량 첨부 원문이 로컬 LLM의 Context를 압도하여 Notebook/Python 코드가 사용자 응답으로 그대로 출력되는 문제를 수정합니다.

## 정책

- 원문은 Backend 내부 캐시에만 유지합니다.
- 인터뷰에는 요구사항 파악에 필요한 구조/단서 중심의 압축 Context만 전달합니다.
- 파일당 8,000자, 전체 18,000자 기본 예산을 적용합니다.
- 응답에서 첨부 원문 대량 복사가 감지되면 재생성합니다.
- 재생성도 실패하면 원문을 노출하지 않는 안전한 다음 질문으로 대체합니다.
