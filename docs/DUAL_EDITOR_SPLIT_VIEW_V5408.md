# v5.408 Dual Editor Split View

## 목적
VS Code처럼 열린 파일 탭의 우클릭 메뉴에서 현재 파일을 왼쪽 또는 오른쪽 편집 그룹에 열어 두 문서를 동시에 비교/편집할 수 있게 합니다.

## 사용 방법
1. 코드 편집에서 파일을 2개 이상 엽니다.
2. 열린 파일 제목 탭을 마우스 오른쪽 클릭합니다.
3. `오른쪽으로 화면 열기` 또는 `왼쪽으로 화면 열기`를 선택합니다.
4. 가운데 세로 구분선을 드래그해 두 화면 너비를 조절합니다.
5. 구분선을 더블클릭하면 50:50으로 돌아갑니다.
6. 보조 화면 Header의 `⇄` 버튼으로 좌/우를 바꾸고 `×`로 분할을 닫습니다.

## 지원 문서
- 일반 Monaco 소스/텍스트 파일
- Jupyter Notebook (`.ipynb`)
- CSV/TSV Spreadsheet
- PDF / PowerPoint Preview
- DB Diagram

## 저장 정책
보조 화면에서 편집한 문서도 같은 열린 파일 버퍼를 사용합니다. 마지막으로 포커스한 편집 화면의 파일을 `Ctrl+S`로 저장하며, `Ctrl+Shift+S`는 기존대로 수정된 열린 파일 전체를 저장합니다.
