# THEANOVA AgentStudio v5.485 NotebookCellVerticalResize

- Notebook Code 셀 하단에 세로 크기 조절 핸들을 추가했습니다.
- 핸들을 위/아래로 드래그하면 코드 영역을 92px~최대 2400px 범위에서 직접 조절할 수 있습니다.
- 파일을 잠깐 전환했다 돌아와도 같은 앱 실행 세션에서는 셀별 사용자 높이를 유지합니다.
- 조절 핸들을 더블클릭하면 해당 셀의 코드 줄 수 기준 자동 높이로 복원합니다.
- Monaco `automaticLayout`을 그대로 사용해 높이 변경 시 코드 편집 영역도 함께 재배치됩니다.
- 기존 Notebook 실행/디버그/북마크/스크롤 경계 전달 기능은 변경하지 않았습니다.
