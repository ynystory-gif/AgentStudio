# THEANOVA AgentStudio v5.164 - Requirement Full Scroll

## 문제
DESIGN 우측 `요구사항 수집 현황` 카드가 화면 하단에 위치할 때, v5.160에서 사용한
`max-height: calc(100vh - 735px)` 고정 계산 때문에 카드 일부가 우측 패널의 `overflow:hidden`
영역 밖으로 밀려났습니다. 내부 목록을 스크롤해도 카드 자체의 아래쪽이 잘려 마지막 요구사항에
도달하지 못할 수 있었습니다.

## 수정
- DESIGN 탭 우측 패널에 `design-info-panel` 클래스를 추가했습니다.
- DESIGN 우측 패널 전체를 단일 세로 스크롤 영역으로 변경했습니다.
- `요구사항 수집 현황`의 고정 `max-height`를 DESIGN 탭에서 해제했습니다.
- 요구사항 목록 내부의 별도 높이 제한/스크롤을 해제하여 전체 항목을 그대로 렌더링합니다.
- 따라서 프로젝트 구성 → Agent 제작 진행 → 요구사항 11개 → 저장/Workflow 버튼까지 한 번의 우측 패널 스크롤로 모두 확인할 수 있습니다.
- 우측 패널 스크롤바 폭과 대비를 키워 현재 스크롤 위치를 쉽게 확인할 수 있게 했습니다.

## 기대 결과
화면 높이가 작거나 상단 카드가 커져도 우측 패널을 끝까지 내리면 요구사항의 마지막 항목과 하단 액션 영역까지 모두 표시됩니다.
