# THEANOVA AgentStudio v5.398 — EducationalCodeProposalExplanation

LLM 대화형 코드 편집의 `AI 변경 제안`을 학습 친화적으로 확장했습니다.

- 제안 코드만 보여주지 않고 `변경 이유 및 코드 설명`을 함께 표시합니다.
- 숫자, dtype, shape, index, 함수 인자, 조건식 등 실제 코드에 들어간 값/표현을 왜 선택했는지 별도 설명합니다.
- 변경된 코드 블록별 실행 의미와 흐름을 `코드 설명` 섹션에서 보여줍니다.
- 전제조건이나 주의점이 있으면 `확인할 점`으로 표시합니다.
- 코드 생성은 기존처럼 코드 전용 LLM 호출로 유지하고, 설명은 별도 compact diff 호출로 생성합니다. 설명 생성이 실패해도 코드 제안은 실패하지 않습니다.
- Notebook Cell과 일반 소스 파일 모두 동일하게 적용합니다.
