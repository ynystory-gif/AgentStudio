# v5.363 AttachmentAnalysisResizableScrollPanel

신규 Agent 인터뷰에서 첨부 문서를 Deep Requirement Mining한 결과가 많을 때 `첨부 파일 AI 정리` 카드가 대화 화면 대부분을 차지하던 UX를 개선합니다.

## 변경 사항

- 전체형 `첨부 파일 AI 정리` 패널의 기본 높이를 화면 높이의 약 42%로 제한합니다.
- 패널 하단의 `높이 조절` 손잡이를 위/아래로 드래그하여 높이를 직접 조절할 수 있습니다.
- 조절한 높이는 브라우저 `localStorage`에 저장되어 다음 표시에서도 유지됩니다.
- `기본 높이` 버튼 또는 조절 손잡이 더블클릭으로 기본 높이로 복원할 수 있습니다.
- 키보드 포커스 상태에서 `↑` / `↓`로 32px, `Shift+↑` / `Shift+↓`로 80px씩 높이를 조절할 수 있습니다.
- 패널 Header와 하단 Action 영역은 고정하고, 파일 목록·AI 요약·추출 요구사항만 중앙 Scroll 영역에서 스크롤합니다.
- 추출 요구사항 목록의 이중 스크롤을 제거하여 전체형 패널은 하나의 세로 스크롤만 사용합니다.
- Compact Sidebar Summary는 기존 레이아웃을 유지합니다.
- 최소 높이 180px, 최대 높이 약 72vh 범위에서만 조절하여 화면을 다시 가리지 않도록 보호합니다.

## 완료 기준

1. 요구사항이 100개 이상이어도 첨부 분석 카드가 Agent 인터뷰 전체 화면을 밀어내지 않는다.
2. 사용자가 하단 조절선을 드래그해 패널을 줄이거나 키울 수 있다.
3. 작은 높이에서는 패널 내부에서 파일·요약·Requirement Registry를 스크롤할 수 있다.
4. 높이를 조절해도 대화 입력 영역과 오른쪽 실시간 설계 패널을 계속 사용할 수 있다.
5. Compact Summary에는 불필요한 Resize Handle이 나타나지 않는다.
