# v5.348 Project Search Tree Toggle & Unified Find

## 목적

코드 편집 화면의 검색 UX를 단순화하고, 프로젝트 파일 검색 결과에서도 폴더 트리를 사용자가 직접 접고 펼칠 수 있도록 한다.

## 변경 사항

### 프로젝트 파일 검색

- 파일명/경로 검색은 기존처럼 이미 로드된 파일 목록을 메모리에서 필터링한다.
- 검색어가 변경되면 일치 파일의 상위 폴더를 최초 1회 자동 확장한다.
- 이후에는 `fileTreeExpanded` 상태를 그대로 사용하므로 검색 중에도 `+ / -` 버튼 또는 폴더 더블클릭으로 접기/펼치기가 가능하다.
- 검색 결과를 강제로 펼친 상태로 고정하지 않는다.

### 본문 텍스트 찾기

- 본문 아래의 `현재 파일 찾기`, `프로젝트 텍스트 찾기` 두 개의 명령 버튼을 제거했다.
- 파일 실행 버튼이 있는 상단 툴바에 `⌕ 찾기` 버튼 하나를 배치했다.
- `⌕ 찾기`를 누르면 기본 scope는 `현재 파일`이고 검색 입력창에 즉시 포커스가 이동한다.
- 열린 검색 패널 안에서 `현재 파일 / 프로젝트 전체` scope를 전환한다.
- 현재 파일 검색은 저장 전 Editor 버퍼를 사용하고, 프로젝트 전체 검색은 저장된 프로젝트 파일을 대상으로 필요할 때만 실행한다.
