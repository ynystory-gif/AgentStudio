# v5.209 Code Proposal Diff Apply Fix

코드 편집기의 파일 단위 AI 수정 요청을 즉시 원본에 반영하지 않고 검토 가능한 제안 흐름으로 변경했습니다.

1. 하단 LLM 코드 채팅에서 파일 단위 변경 요청
2. 우측 `AI 변경 제안` 탭에 제안 코드와 설명 표시
3. `Apply · 비교` 클릭
4. 중앙 Monaco Diff Editor에서 현재 소스와 AI 제안 소스를 좌우 비교
5. `변경 적용` 클릭 시 제안 코드를 현재 Editor buffer에 머지하고 dirty 상태로 유지
6. Ctrl+S 등 기존 저장 흐름으로 실제 디스크 저장

`취소`는 Diff 검토만 닫아 제안으로 돌아가거나, 우측 제안 자체를 폐기할 수 있습니다. AI 응답만으로는 디스크 파일을 자동 저장하지 않습니다.
