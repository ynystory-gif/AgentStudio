# v5.140 Design / Workflow Clean Layout

## 1. 에이전트 설계 / 워크플로우

두 탭에서는 다음 영역을 완전히 제거합니다.

- LLM 대화형 코드 편집
- 터미널

중앙 영역은 에이전트 설계 또는 Workflow 콘텐츠만 전체 높이로 사용합니다.

## 2. 우측 Agent 제작 진행

좁은 우측 패널에서 기존 compact 레이아웃의 최소 너비 때문에 버튼이 잘리는 문제를 수정했습니다.

2단 구성:

1단: 요구사항 → Workflow → 프로젝트 → 개발 진행 상태
2단: 실행 버튼

버튼 배치:
- Workflow 설계 | 프로젝트 생성
- 개발 시작 (전체 너비)

## 3. 프로젝트 클릭

좌측 프로젝트 목록에서 프로젝트를 클릭해 불러오면:

`WORKSPACE → CODE`

즉 코드 편집 탭으로 바로 이동합니다.
