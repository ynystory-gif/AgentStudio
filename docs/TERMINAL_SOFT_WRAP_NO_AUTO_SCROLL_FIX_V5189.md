# v5.189 Terminal Soft Wrap / No Auto Scroll Fix

- 터미널의 긴 명령과 출력은 가로 스크롤 대신 현재 터미널 폭에 맞춰 자동 줄바꿈합니다.
- 문자 입력 시 가로 스크롤 위치를 강제로 이동시키던 로직을 비활성화했습니다.
- 터미널 탭/영역을 선택할 때 스크롤 위치를 강제로 변경하던 로직을 비활성화했습니다.
- 터미널 폭은 FitAddon의 현재 표시 영역 기준 cols/rows만 사용하며, 텍스트 길이에 따라 cols를 확장하지 않습니다.
- xterm 외부 wrapper의 가로 스크롤도 제거해 일반 콘솔처럼 화면 폭 안에서 표시합니다.
