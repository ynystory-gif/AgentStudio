# v5.359 AttachmentAnalysisSummaryVisibility

## 목표
첨부 파일을 AgentStudio가 분석한 뒤, 원문/긴 코드를 노출하지 않고 사용자가 AI가 파악한 내용을 화면에서 직접 확인할 수 있게 한다.

## 표시 내용
- 첨부 파일 목록
- 만들고자 하는 내용
- 핵심 기능
- 입력 / 데이터
- 기술 / 연동
- 추가 확인이 필요한 항목

## 동작
- `첨부만 먼저 분석`: 기존 LLM 기반 통합 상세 요약을 표시한다.
- 일반 `답변 보내기`와 함께 첨부: 별도 두 번째 LLM 대기 없이 안전한 빠른 구조화 요약을 즉시 표시한다.
- Draft 복원: 저장된 첨부 요약과 파일 목록을 다시 표시한다.
- 좌측 요약: compact 형태로 항상 확인할 수 있다.
- 원본/긴 코드/Secret은 사용자 요약 카드에 표시하지 않는다.
