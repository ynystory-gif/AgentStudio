# v5.176 Editor Tab Pin / Save All

## 목적
코드 편집기에서 여러 파일을 동시에 수정할 때 저장과 열린 탭 관리를 VS Code에 가까운 방식으로 개선합니다.

## 변경 사항
- `Ctrl + Shift + S`: 현재 코드 작업공간에서 수정된 열린 파일을 모두 저장합니다.
- 기존 `Ctrl + S`: 현재 선택된 파일만 저장합니다.
- 각 열린 파일 탭에 핀 버튼을 추가했습니다.
  - 핀 고정
  - 핀 고정 해제
- 파일 탭 우클릭 메뉴에서도 핀 고정/해제를 할 수 있습니다.
- 열린 파일 탭 왼쪽의 `편집 ▾` 메뉴에 다음 기능을 추가했습니다.
  - 열린 파일 모두 닫기
  - 핀 고정되지 않은 파일 모두 닫기
- 일괄 닫기 대상에 저장되지 않은 파일이 있으면 닫기 전에 확인합니다.
- 핀 고정된 파일은 `핀 고정되지 않은 파일 모두 닫기`에서 유지됩니다.
