# v5.406 Resizable Code Toolbar Split

- 코드 편집 상단의 **열린 파일 탭 영역**과 **전체 실행/디버그/찾기 도구 영역** 사이에 세로 드래그 핸들을 추가했습니다.
- 핸들을 좌우로 드래그하여 두 영역의 폭을 사용자가 직접 조절할 수 있습니다.
- 전체 실행 도구 영역 폭은 `localStorage(agentstudio.codeToolbar.actionWidth)`에 저장되어 AgentStudio를 다시 열어도 복원됩니다.
- 핸들을 더블클릭하면 화면 폭을 기준으로 기본 너비로 복원합니다.
- 화면이 좁아지면 최소 탭/도구 폭을 보장하고, 도구 영역 내부 가로 스크롤과 기존 우측 정렬 정책은 유지합니다.
