# v5.208 External Notification Ignore Fix

- 외부 파일 변경 알림 항목에 `무시` 버튼을 추가했습니다.
- `modified_conflict` 알림에서 `무시`를 선택하면 현재 AgentStudio의 미저장 편집 내용을 그대로 유지하고 해당 알림만 닫습니다.
- 무시 동작은 디스크 baseline(SHA-256/mtime)을 갱신하지 않으므로 외부 수정 사실 자체를 없던 것으로 만들지는 않습니다.
- 따라서 이후 현재 AgentStudio 내용을 저장하려 할 때 실제 디스크가 여전히 다르면 v5.207의 저장 충돌 Dialog(`외부 파일 로드` / `외부 파일 무시하고 저장` / `취소`)가 표시되어 사용자가 최종 저장 정책을 결정할 수 있습니다.
- 알림에서 `수정`을 선택하면 기존처럼 파일로 이동해 외부 변경 충돌 처리 Dialog를 엽니다.
