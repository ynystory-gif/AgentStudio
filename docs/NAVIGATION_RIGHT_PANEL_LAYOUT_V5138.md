# v5.138 Navigation / Right Panel Layout

## 변경 사항

### 1. 좌측 Global Navigation
홈 아이콘 바로 아래에 `✦ 신규 Agent 설계` 아이콘을 추가했습니다.
클릭하면 기존 `startNewProject()` 흐름을 사용해 신규 Agent 설계 화면으로 이동합니다.

### 2. Workspace 탭 내부 신규 Agent 설계 버튼 제거
에이전트 설계, 워크플로우, 코드 편집, 실행 결과, 분석 리포트에서
기존 `← 신규 Agent 설계` 버튼을 제거했습니다.

신규 Agent 설계 진입은 좌측 Global Navigation 하나로 통일합니다.

### 3. 에이전트 설계 / 워크플로우 탭 우측 패널
두 탭에서는 `프로젝트 파일` 카드를 표시하지 않습니다.

대신 `MCP 도구` 카드 바로 아래에 `Agent 제작 진행` 카드를 표시하고,
다음 버튼을 배치합니다.

- Workflow 설계
- 프로젝트 생성
- 개발 시작

코드 편집 / 실행 결과 / 분석 리포트에서는 기존 프로젝트 파일 트리를 유지합니다.
