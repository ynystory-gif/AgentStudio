# v5.357 AgentProgressHeartbeatUX

## 목적

Agent 설계 인터뷰에서 첨부 파일을 선택한 뒤 장시간 화면 변화가 없어 사용자가 정상 처리와 먹통을 구분하지 못하던 문제를 개선합니다.

## 동작 변경

1. 파일 첨부 시 파일 등록과 Context 준비까지만 자동 수행합니다.
2. Context 준비가 끝나면 `AI 심층 분석 대기` 상태로 멈춥니다.
3. 사용자가 `답변 보내기` 또는 `첨부만 먼저 분석`을 눌러야 LLM 작업을 시작합니다.
4. 실행 중에는 경과시간, 현재 작업, Backend Heartbeat, 첨부 상태를 표시합니다.
5. Backend가 정상이어도 LLM 응답이 오래 걸릴 수 있으므로 45초/120초 지연 상태를 별도 안내합니다.
6. Heartbeat 연속 실패는 Backend 연결 이상 가능성으로 별도 표시합니다.
7. 사용자는 진행 중 요청을 취소하고 실패/취소 요청을 다시 시도할 수 있습니다.
8. 세부 Server 단계 이벤트가 없는 구간에는 가짜 퍼센트를 만들지 않습니다.

## 안전성

- AbortController는 현재 브라우저 요청 대기를 취소합니다.
- 파일 Context와 기존 요구사항 Draft는 취소만으로 삭제하지 않습니다.
- 성공 응답 후에는 기존 방식대로 사용된 Attachment Session을 release합니다.
- 기존 DB 실시간 설계는 사용자가 실제 요구사항을 전송한 이후에만 자연스럽게 갱신됩니다.
