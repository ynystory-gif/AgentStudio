# v5.233 CommentPreservationInsertFix

## 목적
LLM 대화형 코드 편집에서 학습용 힌트/설명 주석을 코드로 치환하지 않고 원문 그대로 보존합니다.

## 동작
- 파일 단위 AI 수정 Prompt에 기존 주석 보존 규칙을 추가합니다.
- LLM 결과에서 기존 full-line comment가 누락되면 Diff 기반으로 원래 변경 위치 앞에 결정적으로 복원합니다.
- `주석 삭제/수정`, `힌트 삭제/수정`, `전체 교체` 등 사용자가 명시적으로 요청한 경우에는 보존 보호를 해제합니다.
- 프로젝트 전체 코딩에도 동일한 보존 규칙과 저장 전 보호를 적용합니다.

## 예
기존:
```python
# 힌트 (실습 1)
# - 연결: ...
# - 커서·조회: ...
# - conn은 ...
```

AI가 힌트 블록 자리에 코드를 생성해도 최종 제안은:
```python
# 힌트 (실습 1)
# - 연결: ...
# - 커서·조회: ...
# - conn은 ...

conn = sqlite3.connect(DB_PATH)
cur = conn.cursor()
```
처럼 주석 아래에 코드가 배치됩니다.
