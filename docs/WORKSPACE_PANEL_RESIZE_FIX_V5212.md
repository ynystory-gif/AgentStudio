# v5.212 Workspace Panel Resize Fix

- 기존 좌측/우측 패널 닫기·열기 기능을 유지합니다.
- 패널이 열린 상태에서는 좌측 패널의 오른쪽 경계와 우측 패널의 왼쪽 경계를 마우스로 드래그하여 폭을 넓힐 수 있습니다.
- 기존 열린 상태 폭을 최소 폭으로 사용하여 그보다 작게 줄어들지 않습니다.
- 중앙 Workspace는 남은 폭을 자동으로 사용하며 최소 작업 폭을 보호합니다.
- 조절한 좌측/우측 폭은 localStorage에 저장되어 탭 이동 및 새로고침 후에도 유지됩니다.
- 접었다 다시 열어도 사용자가 마지막으로 조절한 폭으로 복원됩니다.
