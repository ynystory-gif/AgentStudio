# v5.139 Tab-specific Workspace Layout

## 에이전트 설계 / 워크플로우

중앙 영역은 3행 구조입니다.

1. 탭
2. 설계 또는 Workflow 콘텐츠 (남는 높이 사용, 내부 스크롤)
3. LLM 대화형 코드 편집 + 터미널 (하단 305px 고정)

Agent 제작 진행은 우측 MCP 도구 아래에서만 표시됩니다.

## 코드 편집

Agent 제작 진행 영역을 제거했습니다.

- 코드 편집: 중앙 상단
- LLM 대화형 코드 편집 + 터미널: 하단 고정
- 프로젝트 파일: 우측 유지

## 실행 결과 / 분석 리포트

다음 요소를 표시하지 않습니다.

- Agent 제작 진행
- LLM 대화형 코드 편집
- 터미널
- 우측 프로젝트 파일

중앙 영역은 결과/리포트 콘텐츠가 전체 가용 높이를 사용합니다.
