# v5.120 Workflow Visual Design

기존 v5.119의 동일 크기 노드 나열 방식을 시각적 Workflow 설계도로 변경했습니다.

## AgentStudio 제작 Workflow

4개의 큰 Phase로 묶습니다.

1. 요구 이해
2. Agent 설계
3. 제작
4. 검증 & 완성

각 Phase는 아이콘, 제목, 설명, 세부 Node를 포함합니다.

특히 `대상 Agent Workflow`는 별도 강조색을 사용해
AgentStudio 제작 Workflow 안에서 생성 대상 Agent의 업무 흐름을 설계하는 지점을 구분합니다.

테스트 실패 흐름은 별도의 자동 복구 밴드로 표시합니다.

## 개발 대상 Agent Workflow

자연어 개발 요청을 분석한 뒤 각 업무 단계를:
- 시각 아이콘
- 단계 번호
- 단계명
- 설명
- 연결 화살표

형태로 표시합니다.

추가적으로:
- 분기
- 재시도
- 실패 처리

정책을 별도의 시각 카드로 표시합니다.

## 목표

Workflow를 읽어야 이해되는 화면이 아니라,
화면을 보는 순간 "어디서 시작해 어떻게 흘러가고 어디서 실패 복구되는지" 이해할 수 있는 구조를 목표로 합니다.
