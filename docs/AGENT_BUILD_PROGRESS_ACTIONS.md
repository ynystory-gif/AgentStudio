# v5.124 Agent Build Progress Actions

요구사항 분석 후 다음 제작 단계로 갈 버튼이 없던 문제를 개선했습니다.

## 고정 진행 UI

Agent 설계 인터뷰 입력창 바로 위에 다음 상태와 버튼을 표시합니다.

```text
요구사항
  ↓
Workflow 설계
  ↓
프로젝트 생성
  ↓
개발 시작
```

버튼:
- `◇ Workflow 설계`
- `＋ 프로젝트 생성`
- `▶ 개발 시작`

현재 단계에서 사용할 수 있는 다음 버튼만 활성화됩니다.

## 프로젝트 생성

`＋ 프로젝트 생성`은 기존 `/api/projects/create-agent`를 직접 사용하며:
- 프로젝트 폴더 생성
- 프로젝트 DB 등록
- 현재 프로젝트 Root 설정
- 프로젝트 파일 목록 갱신

을 수행합니다.

## 개발 시작

`▶ 개발 시작`은 `/api/workflow/start`를 호출해 실제 LangGraph Agent Factory Workflow를 시작합니다.

## 자연어 진행 명령

요구사항 분석 완료 후 다음 표현은 일반 대화가 아니라 진행 Intent로 처리합니다.

- 진행 / 진행해 / 진행해줘
- 이대로 진행해줘
- 개발 시작 / 개발해줘
- 만들어줘 / 생성해줘

단, Workflow가 아직 없으면 Workflow 설계로 이동하고,
프로젝트 생성이 필요한 단계라면 UI 버튼으로 해당 단계를 명확하게 안내합니다.
