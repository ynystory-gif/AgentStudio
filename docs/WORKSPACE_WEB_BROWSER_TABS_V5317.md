# v5.317 Workspace Web Browser Tabs

## 목적

v5.316의 웹브라우저를 코드 편집 파일 탭 내부에서 분리하고, 상단 Workspace의 `LLM 리스트` 바로 오른쪽에 독립된 `웹브라우저` 탭으로 이동합니다.

## 탭 구조

- Workspace: `... | 아키텍처 | LLM 리스트 | 웹브라우저`
- Browser Workspace 내부: `기본 웹브라우저 | 승인 URL 1 | 승인 URL 2 | ...`
- `기본 웹브라우저`는 고정 탭이며 닫을 수 없습니다.
- 승인 URL/사용자 추가 탭만 닫을 수 있습니다.

## 웹 감시

Terminal에서 로컬 개발 URL을 감지해도 자동으로 열지 않습니다. 사용자가 다음 중 하나를 선택합니다.

1. 기본 웹브라우저에서 열기
2. 추가 웹브라우저 탭
3. 무시

추가 탭을 승인하면 Browser Workspace로 이동하고 기본 웹브라우저 오른쪽에 새 탭이 생성됩니다.

## 회귀 방지

코드 편집의 열린 파일 탭에는 Browser 탭을 렌더링하지 않습니다. Browser 선택 상태는 SQL/Notebook/Python 파일 활성 상태와 분리합니다.
